# A song for you ♡ — GitHub Pages template

A small, romantic, mobile-friendly music page. No frameworks, build tools, or paid services required.

## Files to add

Keep these files together in the root of your GitHub repository:

- `index.html` — the page (already included)
- `song.mp3` — **your song**, renamed exactly `song.mp3`
- `cover.jpg` — optional square cover image (recommended, but not required)

If you do not add `cover.jpg`, the page uses a flower illustration instead.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository** (for example, `a-song-for-you`).
2. Upload `index.html`, `song.mp3`, and optionally `cover.jpg` to the repository's top-level folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your page address will look like:
   `https://YOUR-USERNAME.github.io/a-song-for-you/`
7. Open that address on your phone to test it.

## Make the QR code

Once the published page works:

1. Copy the full GitHub Pages URL.
2. Paste it into a reputable QR-code generator.
3. Download the QR code as a PNG or SVG.
4. Scan it with your phone and test it before printing or gifting it.

The QR code points to the webpage, not directly to the audio file.

## Personalize the message

Open `index.html` and edit these lines:

- Main heading: `A song for you ♡`
- Subtitle: `A little piece of my heart, just for you.`
- Track title: `A song for you`
- Artist line: `Made with love ♡`
- Footer: `Always yours`

You can also replace the flower placeholder by uploading your own `cover.jpg`.

## Important notes

- GitHub Pages sites are public. Anyone with the URL or QR code can access the page and listen.
- Visitors usually need to tap **Play**; mobile browsers generally block autoplay with sound.
- Check GitHub's current file-size limits before uploading. For a large audio file, use a suitable audio host instead.
- Only upload audio you have the rights or permission to host and share.
